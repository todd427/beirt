Streaming
Beirt is another client for the Messages API, so it can reach any MCP server you can. Connections you configured elsewhere cannot be imported — no API gives them out — but these are remembered between sessions, and export as JSON if you want them on another machine.
Add a server
A new server starts disabled with an empty allow-list — it can reach nothing until you name the tools. Tokens follow the same session-or-remember choice as your API key.

Beirt /bʲɛrˠtʲ/ — “bert”, the final t softened toward tch
Irish for a pair of people. Two independent Claude sessions, side by side, with no shared context.

An open, bring-your-own-key fork of todd427/duel. The original routes through a hosted proxy that holds the key; this one has no server at all — you supply the key and it stays in your browser.

Designed and built by FoxxeLabs. MIT licensed. No analytics, no logging, no build step.

Themes: Paper and Folio are the house pair, Slate and Ink are neutral, Terminal comes from rialú.
